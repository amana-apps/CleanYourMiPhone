# Security policy

## Reporting a problem

If you find a security problem in the tool, please don't describe it in a public
issue. Use **Report a vulnerability** on the
[Security tab](https://github.com/amana-apps/CleanYourMiPhone/security), or open
an issue asking for a private way to share the details.

If a package list caused a boot loop or data loss, open a normal issue so others
are warned quickly.

## What the tool does with your data

The tool talks only to the phone connected over USB. It sends nothing over the
internet. Package backups stay in the `backups/` folder on your computer.
